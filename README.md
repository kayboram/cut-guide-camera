# 컷가이드 카메라

휴대폰 카메라 위에 촬영 컷 정보와 예시 사진을 반투명하게 띄워 보는 정적 웹앱입니다. 한 컷에 여러 예시 사진을 등록해 바꿔 볼 수 있고, 업체 필수 조건을 촬영 화면 상단에서 확인할 수 있습니다. 서버나 외부 라이브러리가 없고, 사진은 기기 안에서만 처리합니다.

공개 주소: https://kayboram.github.io/cut-guide-camera/

## 로컬 실행

HTTPS가 아닌 `localhost`에서도 카메라 사용은 허용됩니다.

```bash
cd cut-guide-camera
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 사용 흐름

1. 컷 리스트와 업체 필수 조건을 입력합니다.
2. 컷마다 예시 사진을 여러 장 등록합니다.
3. 촬영 화면에서 예시 사진을 고르고 투명도를 조절해 촬영합니다.
