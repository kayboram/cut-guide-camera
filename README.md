# 컷가이드 카메라

캠페인을 고르면 필요한 사진 목록을 보여 주고, 아이폰 기본 카메라로 찍은 사진을 각 칸에 올리는 정적 웹앱입니다. 캠페인마다 완료 상태를 따로 기억합니다. 서버나 외부 라이브러리가 없고, 사진과 영상은 기기 안에서만 처리합니다.

공개 주소: https://kayboram.github.io/cut-guide-camera/

## 로컬 실행

```bash
cd cut-guide-camera
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

배포 전 정적 검증:

```bash
node verify.mjs
```

## 사용 흐름

1. 캠페인을 고릅니다.
2. 아이폰 기본 카메라로 필요한 사진과 영상을 찍습니다.
3. 목록에서 원하는 칸의 `사진 올리기` 또는 `영상 올리기`를 누르고 사진첩에서 고릅니다.
4. 올리면 완료 표시와 미리보기가 남고 다음 미완료 칸으로 이어집니다.

예전 버전에서 넣어 둔 사진 데이터는 삭제하지 않으며, 목록 위의 `기존 저장 사진 꺼내기`에서 사진첩으로 옮길 수 있습니다.
