# 컷가이드 카메라

캠페인을 고르면 찍어야 할 사진 목록을 보여 주고, 각 칸에서 바로 휴대폰 카메라를 여는 정적 웹앱입니다. 캠페인마다 촬영 진행 상태를 따로 기억합니다. 서버나 외부 라이브러리가 없고, 사진은 기기 안에서만 처리합니다.

공개 주소: https://kayboram.github.io/cut-guide-camera/

## 로컬 실행

HTTPS가 아닌 `localhost`에서도 카메라 사용은 허용됩니다.

```bash
cd cut-guide-camera
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 사용 흐름

1. 캠페인을 고릅니다.
2. 찍어야 할 사진 목록에서 원하는 칸의 `카메라로 찍기`를 누릅니다.
3. 화면의 사진 설명과 팁을 보고 촬영합니다.
4. 촬영을 마치면 완료 표시가 남고 다음 칸으로 이어집니다.

예전 버전에서 넣어 둔 사진 데이터는 삭제하지 않으며, 목록 위의 `기존 저장 사진 꺼내기`에서 사진첩으로 옮길 수 있습니다.
