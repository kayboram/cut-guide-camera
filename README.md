# 컷가이드 카메라

캠페인을 고르면 필요한 사진 목록을 보여 주고, 아이폰 기본 카메라로 찍은 사진을 각 칸에 올리는 정적 웹앱입니다. 캠페인마다 완료 상태를 따로 기억합니다. 사진과 영상은 전송 버튼을 누르기 전까지 기기 안에서만 처리합니다.

공개 주소: https://kayboram.github.io/cut-guide-camera/

## 로컬 실행

```bash
cd cut-guide-camera
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

배포 전 정적 검증:

```bash
node verify.mjs
```

## 사용 흐름

1. 캠페인을 고릅니다.
2. 아이폰 기본 카메라로 필요한 사진과 영상을 찍습니다.
3. 목록에서 원하는 칸의 `사진 올리기` 또는 `영상 올리기`를 누르고 사진첩에서 고릅니다.
4. 올리면 완료 표시와 미리보기가 남고 다음 미완료 칸으로 이어집니다.

예전 버전에서 넣어 둔 사진 데이터는 삭제하지 않으며, 목록 위의 `기존 저장 사진 꺼내기`에서 사진첩으로 옮길 수 있습니다.

## 멀티카 전송

사진을 한 장 이상 올리면 목록 위와 아래에 `완료 · 멀티카로 전송` 버튼이 나타납니다. 토큰은 공개 코드에 포함하지 않고 브라우저의 `cgc-multica-settings-v1` 로컬 저장소에만 보관합니다. 멀티카 API의 브라우저 접근 제한 때문에 프록시가 없는 아이폰에서는 ZIP 공유와 댓글 본문 복사를 사용합니다.

Cloudflare Worker 프록시 코드와 배포 순서는 [docs/multica-proxy.md](docs/multica-proxy.md)에 있습니다.
